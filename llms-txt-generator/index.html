# Acme Running

> Acme Running sells trail and road running shoes online and ships to the EU and US.

Prices are in EUR. All shoes have a 60-day return window.

## Products

- [Trail shoes](https://acme.example/trail/): Full trail range with sizes and prices

## Optional

- [Blog](https://acme.example/blog/): Training guides
  • H1 with the site or project name — the only required element.
  • Blockquote with a one-sentence summary. Write it the way you’d want an AI to describe you.
  • Free text for key facts: markets, prices, policies, what you don’t do.
  • H2 sections of Markdown links, each with an optional : description.

What llms.txt does — and doesn’t — do

Be clear-eyed about it. llms.txt was proposed by Jeremy Howard of Answer.AI in September 2024 to help models use websites at inference time. Developer tools and some AI agents read it, and many documentation sites publish one. But Google has said it does not use llms.txt in Search, and none of the major AI search products document it as a signal for citations.

What actually decides whether ChatGPT, Perplexity or AI Overviews can cite you is the basics: crawlers allowed, content in the HTML, and pages that answer questions clearly. Check those first with the AI crawler checker and the full audit.

How to write a good llms.txt

  • Keep it short: the 10–30 pages that answer the questions customers actually ask.
  • Describe each page by the question it answers, not by marketing copy.
  • Use absolute URLs that return 200 and are not blocked in robots.txt.
  • Put archives and secondary pages under ## Optional.
  • Update it when you add or retire important pages.

Frequently asked questions

What is llms.txt?

+

llms.txt is a proposed standard (llmstxt.org, 2024) for a Markdown file at the root of a site that tells language models what the site is and which pages matter most, with a one-line description of each. It is a curated map, not an access-control file like robots.txt.

Does llms.txt improve SEO or AI search rankings?

+

There is no evidence that it does today. Google has said it does not use llms.txt for Search, and no major AI search engine documents it as a ranking or citation signal. It is cheap to add and useful for AI coding assistants and agents that do read it, so treat it as a low-effort extra — not a fix for crawlability or content problems.

What is the difference between llms.txt and robots.txt?

+

robots.txt tells crawlers what they may fetch. llms.txt tells models what is worth reading and what each page is about. llms.txt cannot block anything.

What should go in the Optional section?

+

Pages a model can skip when its context is limited — blog archives, changelogs, legal pages. The spec reserves the section name “Optional” for exactly this.

How do I add llms.txt to WordPress or Shopify?

+

On WordPress, upload the file to your site root over SFTP or your host’s file manager; some SEO plugins, including Yoast SEO, can generate one. Shopify does not allow files at the root, so upload it under Content → Files and create a URL redirect from /llms.txt to that file.
