JSON-LD schema generator

JSON-LD is a script tag that describes a page in Schema.org terms. Search engines can read it without guessing from HTML. Pick a type below, fill the fields you actually have on the page, and copy the script into your theme or layout.

What you should put in the markup

Only properties that are true on the live page. If the page does not show reviews, do not add AggregateRating. If the product is not for sale, do not invent an Offer. Google spam policies treat fake ratings as a ranking risk, not a shortcut.

Valid markup does not guarantee a rich result. Eligibility also depends on Google policies, crawl, and ranking.

Where to paste it

  • Next.js App Router: a script type="application/ld+json" in the Server Component for that route.
  • WordPress: a small hook on wp_head, or your theme’s header — not a second copy of the same entity on every page.
  • Shopify: a snippet included in theme.liquid or the product template, using Liquid for live price and availability.
